# Maison électrique – EPI (NF C 15-100)

Site pédagogique pour faire travailler les élèves sur les normes électriques d'une maison :

1. **Normes et installation** : en cliquant sur une pièce de la maison 3D, l'élève règle des compteurs (prises, circuits, luminaires…) en respectant les normes. Certains équipements sont des pièges.
2. **Choix des appareils** : pour chaque pièce, choisir parmi plusieurs appareils (puissance, classe énergie, prix, argument du vendeur).
3. **Compteur et tableau électrique** : un compteur de type Linky et un tableau de disjoncteurs montrent l'énergie consommée selon l'installation choisie.

Site statique (un seul fichier `index.html`, three.js chargé depuis un CDN). Aucune installation nécessaire : ouvrir `index.html` dans un navigateur.
